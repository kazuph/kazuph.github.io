# 早押しクイズバトル

4人がオンラインの同じ部屋に入って対戦する、早押しクイズのWebアプリ。
Cloudflare Workers のローカル開発環境（`wrangler dev`）だけで動く。

## 起動方法

```bash
npm install
npx wrangler dev
```

ブラウザで http://localhost:8787 を開く。ログイン・デプロイは不要。
4人で遊ぶときは、別のブラウザ／シークレットウィンドウ／スマホなどで同じ URL を開き、
ロビーに表示される部屋コード（6文字）を入力して参加する。

## 遊び方

1. 名前を入れて「部屋を作る」か、部屋コードを入れて「参加する」（1部屋4人まで）。
2. 部屋を作った人（ホスト）が、2〜4人そろったら「開始」を押す。
3. 問題が出たら「早押し！」ボタン（またはスペースキー）を押す。最初に押した1人だけが回答できる。
4. 回答者は10秒以内に4択から選ぶ。正解 +10点、不正解 −5点。
5. 不正解の人はその問題ではもう押せない。残りの人で早押しを続ける。
6. 全10問の終了後、最終順位が表示される。
7. 再読み込みや一時的な回線切断のあとは、自動で再接続し、同じ名前・点数で復帰する。

## テスト方法

```bash
npm test              # 型検査 + 単体テスト + ブラウザE2E をすべて実行
npm run test:type     # tsc --noEmit
npm run test:unit     # vitest（tests/unit/game.test.ts）
npm run test:e2e      # Playwright（tests/e2e/*.spec.ts）
```

E2E は `wrangler dev` をテスト専用ポート（18878）で自動起動するので、
普段の開発サーバー（8787）とぶつからない。実時間で実行するため
（問題20秒・回答10秒の締め切りを縮めない）、全体で2〜3分かかる。

| テスト | 内容 |
|---|---|
| `tests/unit/game.test.ts` | ゲーム規則の単体テスト（27件）。定員・開始条件、4人の早押し24通り全順列、正誤点数、10秒/20秒切れ、10問終了と同点順位、出題中の正解秘匿など |
| `tests/e2e/lobby.spec.ts` | 4人参加・5人目の「満員」拒否、1人では開始不可。ロビーの撮影 |
| `tests/e2e/battle.spec.ts` | 4人同時押し（3問以上で回答権が1人だけ）、不正解 −5点と再開、再読み込み復帰、5秒オフラインからの自動再接続、残り時間の同期（差1秒以内）、10問完走と最終順位の一致。各画面の撮影 |
| `tests/e2e/timeout.spec.ts` | 誰も押さないと実時間20秒で正解表示、回答放置で実時間10秒で −5点 |

## 構成（概要）

- `src/worker.ts` — `/api/*` の受付。部屋の作成・参加を Durable Object に振り分け、`/ws` をそのまま渡す。
- `src/room.ts` — Durable Object（1部屋＝1オブジェクト）。WebSocket（Hibernation API）の受け付け・全員への配信、Alarm による締め切り管理、SQLite への保存。
- `src/game.ts` — ゲーム規則の純粋関数（副作用なし、時刻は引数）。正誤判定・点数・早押し順はすべてサーバー側で決める。
- `src/questions.ts` — 内蔵の日本語4択問題（14問。毎回シャッフルして10問出題）。
- `public/` — ビルドなしの素の HTML / CSS / JS。PC幅とスマホ幅（390×844）に対応。
- `ARCHITECTURE.md` — 採用理由と不採用案の記録。
- `RESULT.md` — 必須機能11項目の達成表。
- `.artifacts/` — E2E が撮影した各画面のスクリーンショット（git 管理外）。
