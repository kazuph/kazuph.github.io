# ひらめき早押し

Cloudflare Workers のローカル環境で遊ぶ、2〜4人の早押しクイズです。Cloudflare へのログインやデプロイは不要です。

```sh
npm ci
npm run dev
```

http://localhost:8795 を開き、名前を入力して部屋を作るか、6文字の部屋コードで参加します。別のプレイヤーは別ブラウザやプライベートウィンドウで開いてください。ホストが開始し、早押しボタンまたはスペースキーで回答権を取ります。

```sh
npm test
```

`npm test` は型検査、Vitest の単体テスト、Wrangler を自動起動する Playwright のブラウザテストを順に実行します。テストにはインストール済みの Google Chrome が必要です。ブラウザテストは実際の制限時間を使うため数分かかります。
