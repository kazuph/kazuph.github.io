# 早押しスタジオ

Cloudflare Workers のローカルランタイムで動く、4人用のリアルタイム早押しクイズです。部屋の状態、早押し順、正誤判定、点数は Durable Object が管理します。外部 API や Cloudflare アカウントは使いません。

## 起動

必要なものは Node.js と npm です。依存パッケージを入れ、ローカル Worker を起動します。

```sh
npm install
npm run dev
```

ブラウザーで <http://localhost:8787> を開きます。部屋を作った人が表示されたUUID形式の部屋コードを共有し、他の人が名前とコードを入力して参加します。2〜4人でホストが開始できます。

`wrangler dev` は Cloudflare Workers のローカル実行です。このリポジトリにはデプロイ用コマンドを用意していません。

## テスト

```sh
npm test
npm run typecheck
```

`npm test` は `wrangler dev` を `127.0.0.1:8787` で起動し、Chromium の独立したページから実際の Worker・Durable Object・WebSocket に接続する Playwright E2E です。テストは次を確認します。

- 4人の同時参加と5人目の満員拒否
- 複数人の同時押しで回答権が一人だけに決まること
- クライアントが偽の得点を送ってもサーバー採点が優先されること
- 誤答者の減点・再押下禁止と、次のプレイヤーによる回答
- 再読み込み後に同じプレイヤーと得点で復帰すること
- 回答権10秒の期限と、問題20秒の期限
- 内蔵10問を完走し、全員に同じ最終順位を表示すること
- PC幅とスマートフォン幅のロビー・出題中・回答中・結果画面

スクリーンショットは `.artifacts/screenshots/` に保存され、Git には追加しません。

## ルール

- 1部屋は最大4人、開始には2人以上が必要です。
- 問題は内蔵の日本語4択10問です。
- サーバーが先に受信した早押しだけが回答権を得ます。
- 回答権を得てから10秒で回答を締め切ります。時間切れはその問題で回答できなくなりますが、誤答ではないため点数は変わりません。
- 正解は+10点、誤答は-5点です。誤答者は同じ問題で再度押せません。
- 問題は出題から20秒で締め切ります。全員が回答できなくなった時点でも締め切り、正解を表示して次問へ進みます。
- 前問の正解は次問画面の案内欄にも表示されます。
- 再読み込み時はブラウザーに保存した部屋コードとプレイヤートークンで復帰します。点数と進行状況は Durable Object Storage に保存されます。
