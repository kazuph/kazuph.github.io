# QUICK / 早押しクイズ

2〜4人が同じ部屋で遊ぶ、日本語10問の早押しクイズ。Cloudflare Workers / Durable Objects / WebSocket を使い、**ローカルだけ**で動かします。Cloudflareへのログイン・デプロイは不要です。

## 起動

Node.js 22以降と npm を使用します。

```sh
npm ci
npm run dev
```

http://localhost:8784 を開きます。別のブラウザや独立したブラウザプロファイルを2〜4個使い、名前を入れて部屋を作成し、表示された8桁のコードで参加してください。同じブラウザプロファイルで同じ部屋を開くと、同じプレイヤーとして復帰します。ホストの「クイズをはじめる」で開始します。サーバーを止める場合は起動したターミナルで Ctrl+C。

アプリのポートは8784固定。inspectorは0指定で空きポートを選びます。devサーバーはループバックで待ち受けます。この課題の動作確認は同じMac上の独立ブラウザで行っており、別端末からlocalhostには接続できません。

## ルール

- 全10問、日本語の4択。外部APIや配信サービスは使いません。
- サーバーが最初に受信した早押しだけに回答権。スペースキーでも押せます。
- 回答は10秒以内、ただし出題から20秒で問題全体が終了。正解は+10点、不正解は−5点。
- 不正解・無回答で回答期限を過ぎた人は、その問題で再び押せません。無回答の得点変更はありません。
- 正解者が出る、全員の回答権がなくなる、または20秒になると正解を公開し、3秒の表示後に自動で次へ進みます。10問目の公開後は最終順位です。同点は同順位（1、1、3位方式）。
- 再読み込みや一時的な回線切断では点数と席を維持します。Cookieの削除や別プロファイルでは本人確認ができません。

## テスト・ビルド

```sh
npm run test:unit
npm run test:e2e
# 上の両方を順に実行
npm test
# バンドルのみ。--dry-runなのでアップロード・デプロイはしない
npm run build
```

E2EはPlaywright Testで実際のChromiumと`wrangler dev --local`に接続します。サーバー未起動ならテストが8784に起動・終了します。すでに起動済みならそのサーバーを使用します。時間を進める偽時計やネットワークのモックは使いません。10秒/20秒の実時間待ちを含むため、全体で約1分かかります。

**ブラウザはインストールしません。** 実行環境にPlaywright対応Chromiumがすでに必要です。別の既存Chromiumを使う際は実行ファイルの絶対パスを渡せます。

```sh
PLAYWRIGHT_EXECUTABLE_PATH=/absolute/path/to/existing/chromium npm run test:e2e
```

### テストの内訳

| ファイル | 検証する内容 |
| --- | --- |
| `tests/unit/game.test.js` | 定員・開始条件、24通りの先着順、得点、権限、期限境界、古い操作、10問、同点、秘密情報の除外 |
| `tests/e2e/protocol.spec.ts` | 実WebSocket4本の競合、最初の1人だけ、非ホスト開始拒否、他人の回答/申告点数の拒否、古い問題への操作拒否 |
| `tests/e2e/quiz.spec.ts` | 通常UIで4人完走、満室、再読込、画面同期、PC/スマホ、実時間の回答/問題期限、全員失敗、一時オフラインから復帰、HTTP入力と認証の境界 |

スクリーンショットは `.artifacts/screenshots/` に自動保存。ロビー・出題中・回答中・結果の各PC/スマホを取得し、横はみ出し・操作や行の重なりを数値で検査します。寸法結果は `.artifacts/layout/`、E2E全結果は `.artifacts/e2e-results.json`、失敗時のトレースは `test-results/`。これらはコミットしません。

## 構成・データ

- `src/game.js`: 内蔵問題とサーバーの状態遷移。
- `src/worker.js`: HTTP入口、部屋単位のDurable Object、SQLite保存、認証、WebSocket、Alarm。
- `public/`: 外部CDNも画像も読み込まない、PC/スマホ対応UI。
- `docs/ui-reference/`: **実装前にimage_genで作成・コミット**した4画面の参考画像。UIは色、見出し、余白、罫線と点数欄の構成を参照しています。生成画像内の誤った採点や未依頼の設定機能は実装していません。
- `ARCHITECTURE.md`: 選定理由、代替案、通信と期限の設計。
- `RESULT.md`: 要件ごとの実証結果。

部屋と得点は `.wrangler/state/` のローカルSQLiteに保存します。切断者の席は解放せず、再接続のために確保します。退席・ホスト交代・再戦・部屋削除・問題編集はこの課題の範囲外です。Cookieは本人の参加資格なので共有しないでください。

依存はlockfileで固定。Wrangler 4.149.0は2026-10-08公開で7日以内の新規バージョンではありません。互換日は同梱ランタイムが対応する2026-10-06です。Windows向けの実装・検証、CI、クラウド上の動作確認は行いません。
