# 実装・検証計画

依頼元は TASK.md。4人が独立したブラウザから参加し、10問の早押しを最後まで遊ぶ。
元のチェックアウトは main、リモートなし。作業は `.worktrees/feat/quiz` の `feat/quiz`。
委任・デプロイ・ログイン・push はしない。既存のアプリ・呼び出し元・テストはなく、新規制作。

## 設計と検証

1. 画像生成で4画面の参考を作り、保存・Preview確認・コミットを終えてから実装する。
2. 1部屋1 Durable Object、SQLiteの同期保存、WebSocketで状態配信。先着1人、ホスト権限、10秒・20秒期限と古い操作の拒否を状態機械の境界テストで確認する。
3. HttpOnly Cookieで同じプレイヤーの再接続を認証。切断で席・得点を削除しない。
4. 参考のクリーム色・朱色・緑色、セリフ見出し、罫線・点数欄をPCとスマホに実装。
5. Playwrightの4独立コンテキストで定員、同時押し、再読み込み、実時間の期限、全10問、順位、全画面の同期を確かめる。画面の幅・重なりを数値検査する。
6. 4状態×PC/スマホの画像と検証ログを追跡外の `.artifacts/` に保存。README、ARCHITECTURE、項目別RESULTを整え、READMEのコマンドを実行する。
7. 区切りごとにコミットし、上司p39へ完了報告と配送確認を行う。

成功はTASKの11項目と納品物すべての証拠がそろった時点。未検証を達成扱いにしない。
外部設定・権限が必要なら報告し、それに依存しない作業を完了してから待つ。
