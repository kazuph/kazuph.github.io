# QuickBell 早押しクイズ

Cloudflare Workers のローカルランタイムで、2〜4人が同じ部屋で遊ぶ早押しクイズです。Cloudflare アカウントへのログインやデプロイは使いません。

## 起動

必要環境は Node.js 22 と npm です。

```sh
npm ci
npm run dev
```

ブラウザーで <http://localhost:8794> を開きます。`wrangler dev` が Durable Objects、WebSocket、Alarm、静的ファイルをローカルで動かします。部屋やゲーム状態は `.wrangler/state/` に保存され、再起動後もローカル状態を使えます。

## テスト

Chromium が利用できる環境で、以下を実行します。

```sh
npm test
```

`npm test` は TypeScript 型検査、ゲーム規則の単体テスト、Wrangler を起動する Playwright ブラウザーテストを順に実行します。ブラウザーテストは早押し競争、再読み込み、回線切断、実時間の10秒・20秒期限、10問の完走を確認するため、時間を短縮していません。Playwright の Chromium がまだ無い環境では、初回だけ `npx playwright install chromium` を実行してください。

ブラウザーテストはロビー・出題中・回答中・結果を PC とスマートフォン幅で撮影し、`.artifacts/quickbell/` に保存します。このフォルダーは Git に含めません。

## 遊び方

名前を入力して部屋を作るか、6文字の部屋コードを入力して参加します。ホストは2〜4人で開始できます。各問題は最大20秒、早押しした人は最大10秒で選択肢を答えます。正解は10点、不正解と回答時間切れは5点減点です。全10問終了後に順位を表示します。

スペースキーでも早押しできます。ページ再読み込みや一時的なオフラインから戻ったときは、保存済みの参加情報で同じプレイヤーとして再接続します。
