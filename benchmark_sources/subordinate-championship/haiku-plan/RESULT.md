依頼: TASK.md の遊び方11項目・テスト・UI を、PLAN.md のとおりに作って確かめる。
確認: `npm test`（型検査 OK ／ 単体テスト 24件 OK ／ E2E 8件 OK。約1.5分）。

## 代用・割り切り（正直に書く）

- **同時押しの送り方**: TASK の「Promise.all で click」の代わりに、Playwright の `dispatchEvent("click")` を4人分まとめて送っている。理由: Playwright の `click` は「押せる状態になるまで待つ」ため、負けた人の押下が後から届き、別の問題で時間切れになる誤動作を起こした（テストの方の問題。アプリの動作は正しかった）。押せない人の押下は、サーバーが無視する。
- **画面の表示の追加**: 10秒切れや不正解で失格した後、問題に戻るときの説明がなかったため、出題中の状態に「直近の失格（誰が・時間切れか不正解か）」を追加し、「○○さんは時間切れ -5点」と出すようにした。正解の番号は含めない。PLAN.md に明記のない項目の追加なので、ここに記す。
- **未確認**: 同じ人が別の画面で開いたとき古い接続を閉じる処理（close code 4000）は実装のみで、E2E では確かめていない。

## 途中で見つけて直したこと

1. 閉じかけの WebSocket へ配信して例外が出ていた → 配信時に例外を捕まえ、閉じかけの接続には送らないようにした。
2. Vitest が E2E のファイルも拾っていた → `vitest.config.ts` で単体テストだけを対象にした。
3. 型検査の `@types/node` が無かった → E2E 用の型定義を devDependencies に追加（22.19.0）。

## 再現の手順

```bash
npm install
npm test           # 型検査 → 単体 → E2E（E2E は 8792 番で wrangler dev を自動起動する）
```

E2E は実時間で遊ぶ。ブラウザが無い場合は `npx playwright install chromium`。
