# HAYA! — 4人オンライン早押しクイズ

2〜4人で同じ部屋に集まり、全10問に挑戦する日本語の早押しクイズです。正解 +10点、不正解 −5点。Workers + Durable Objects + WebSocket を公式のローカルランタイムで動かします。**Cloudflareへのログイン・デプロイは不要です。**

## 起動

必要なもの: Node.js 22.22以上、npm、macOSにインストール済みのGoogle Chrome（E2E用）。ブラウザのインストールコマンドは実行しません。

```sh
npm ci
npm run dev
```

`http://localhost:8783` を開きます。別ポートに常駐しません。inspectorは空きポートを自動選択します。停止はCtrl+C。`wrangler dev --local` はローカルのworkerd/SQLiteを使い、Cloudflareアカウントの認証は不要です。

## 遊び方

1. 名前を入力し「部屋を作る」。表示された8文字の部屋コードを友だちに伝えます。
2. ほかのプレイヤーは同じURLを別のブラウザ／タブで開き、名前とコードを入力して「参加する」。同じPCでも4つのタブで遊べます。
3. 2〜4人でホストが「ゲームを開始する」。5人目には満員と表示されます。
4. 問題を読んで「早押し！」（PCではスペースキーも可）。サーバーに最初に届いた1人だけが、10秒以内に4択から答えます。
5. 不正解・回答時間切れは−5点。その問題ではもう押せず、残りのプレイヤーが押せます。正解は+10点。
6. 正解・全員失格・出題から20秒経過で次の問題へ自動進行します。直前の正解と解説は画面下に残ります。10問後に全員の最終順位を表示します。同点は同順位です。
7. 再読み込みや一時的な通信断では、同じタブのsessionStorageに保存した参加情報から自動復帰します。点数・回答権・期限はサーバー側にあります。接続が切れても時間は進みます。

画面を別端末のブラウザから開くネットワーク公開やTLSの設定は行っていません。今回の納品はlocalhostで複数ブラウザを使うローカル開発限定です。タブを閉じて参加情報を消した後の本人復元は対象外。ゲーム途中の新規参加はできません。

## 検証

```sh
npm test
```

型検査→状態機械の単体テスト→実際のChromeとWranglerを使ったE2Eの順です。E2Eは8783に未起動なら公式ローカルサーバーを起動し、終了時に止めます。すでに `npm run dev` が起動していればそれを利用します。

```sh
npm run typecheck
npm run test:unit
npm run test:e2e
```

- 単体: ホスト・開始人数、排他回答権、不正解の失格と重複減点防止、10秒／20秒ちょうどの境界、全員失格、10問終了・同点順位、状態のシリアライズ、未公開正解・他人のトークンの非公開。
- E2E: PC／スマホで4つの独立したブラウザコンテキストが10問を対戦。同時押しで1人だけ回答、5人目拒否、リロード・オフライン復帰、得点・回答者・絶対期限の全員一致を検査。
- 実時間の期限: サーバー時計を変更せず、10秒の未回答失格と20秒の無操作自動進行を待って検証します。テストだけの短縮・バックドア・モックはありません。
- 実API: 空の名前、他オリジン、存在しない部屋、偽トークン、非ホスト開始、回答権なし、古い問題への二重回答、途中参加を拒否します。
- UI: 1440×1000と390×844でロビー／出題中／回答中／最終結果の8枚を `.artifacts/` に保存。横はみ出し・選択肢の重なりを座標とスクロール幅で検査し、JSONも保存します。

`.artifacts/e2e-results.json` が機械可読の結果、失敗時のトレースは `test-results/` に保存されます。`.artifacts/` とテスト一時出力はコミットしません。項目別の実行結果は [RESULT.md](RESULT.md)、設計・選ばなかった構成・解釈は [ARCHITECTURE.md](ARCHITECTURE.md) に記載します。

## 状態とローカルデータ

Durable Objectsの状態は `.wrangler/` に保存されます。再起動後も同じ作業ディレクトリとブラウザ参加情報を使用すれば復帰できます。`npm ci` はデータを消しません。部屋の自動削除やロビーからの退出／ホスト移譲は追加していません。

## 納品時の配置

元のチェックアウトは main を維持し、開発はその配下 `.worktree/quiz-local` の `quiz-local` ブランチで実施しています。実装と証拠を確認後、mainへfast-forwardして同じソースを納品します。スクリーンショットは元チェックアウトの `.artifacts/` にも保存します。push先はありません。
