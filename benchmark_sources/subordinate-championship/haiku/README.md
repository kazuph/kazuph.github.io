# 早押しクイズ バザー対決（4人オンライン・Cloudflare・ローカル開発）

4人が同じ部屋に入り、10問の4択クイズを早押しで遊ぶWebアプリです。Cloudflare Workers（Durable Objects・WebSocket・Workers Assets）で動きます。**ローカル開発（`wrangler dev`）だけ**を対象にし、デプロイはしません。Cloudflare へのログインも不要です。

## 必要なもの

- Node.js 22 以上（確認したのは v22.22.0）
- npm
- Playwright の Chromium（E2E 用。未導入なら `npx playwright install chromium`）

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで **http://localhost:8782** を開きます。別のPCから開く場合は、Tailscale などで同じ 8782 番ポートに届く URL を使ってください。

遊び方
1. 名前を入れて「部屋を作る」。画面に出る4文字の部屋コードを、ほかの3人に伝えます。
2. ほかの人は名前と部屋コードを入れて「参加する」。5人目は「定員4人で満員のため、入れません」と表示されます。
3. ホストが「ゲーム開始」を押すと始まります（開始できるのは2〜4人のとき）。
4. 問題が出たら「押す！」。最初に押せた1人だけが10秒以内に4択から選べます（正解+10点、不正解・時間切れ-5点）。
5. 不正解の人はその問題では押せません。全員が押せなくなるか、問題から20秒たつと正解を表示して次へ進みます。
6. 10問終わると最終順位が出ます。

途中で再読み込みしたり回線が切れたりしても、同じ画面に戻ると同じプレイヤーとして点数を保ったまま復帰します。

## テストの実行

```bash
npm test
```

これは次の4つを順に実行します。個別にも実行できます。

| コマンド | 内容 | 必要なもの |
|---|---|---|
| `npm run typecheck` | TypeScript の型検査 | なし |
| `npm run test:unit` | ゲームのルール（早押し・点数・時間切れ・定員・退出など）の単体テスト（19件） | なし |
| `npm run test:integration` | 本物の `wrangler dev`（テスト用ポート 8790）に WebSocket で接続する結合テスト（11件）。同時押し・再接続・20秒の時間切れを含む | 約40秒。テストが自分で起動・停止する |
| `npm run test:e2e` | 実ブラウザで4人（別々のブラウザ）が遊ぶ E2E（PC幅 1280×800 とスマホ幅 390×844 の2種類、計4件）。スクリーンショットを `.artifacts/screenshots/` に保存 | 約3分。テストが自分で起動・停止する |

テストが使うポートは 8790（開発用の 8782 とは別）です。テストの保存先は `.wrangler/test-state` で、開発用の `.wrangler/state` とは分けてあります。

## ディレクトリ

```
src/game.ts        ゲームのルール（純粋関数。時刻を引数で受け取るので待たずにテストできる）
src/room.ts        部屋の Durable Object（状態の保存・WebSocket・alarm による時間切れ）
src/index.ts       Worker の入口（部屋を作る・参加・接続の振り分け）
src/questions.ts   内蔵の日本語の問題（16問から毎回10問を選ぶ）
public/            画面（HTML・CSS・JavaScript。ビルド工程なし）
tests/             単体・結合・E2E のテスト
ARCHITECTURE.md    構成の選定理由と、選ばなかった案
RESULT.md          遊び方11項目とテスト・UI の達成状況の証拠表
```

## 注意

- 認証はありません。プレイヤーの識別はブラウザに保存される `playerId`（ランダムな ID）だけです。ローカルで遊ぶ前提の作りです。
- 進行中のゲームから抜ける操作はありません。画面を閉じても席と点数は残り、同じ部屋・同じ端末で戻れます。ロビーでの「部屋を出る」は席を消します。
