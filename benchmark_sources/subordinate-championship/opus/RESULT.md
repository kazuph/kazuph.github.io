# RESULT — 4人オンライン早押しクイズ

依頼: Cloudflare 上で動かす前提の、4人が同じ部屋で対戦する早押しクイズを、ローカル開発環境（`wrangler dev`、`http://localhost:8786`）だけで動くように作る。

結論: 遊び方11項目・テスト・UI のすべてを、自動テストと実画面のスクリーンショットで確かめました。未達はありません。確かめ方に限りがある点は表の下の「確かめ方の限界」に書きました。

- 最終確認: `npm run test:all`（型検査 → 単体＋結合 49件 → ブラウザE2E 11件）がすべて成功（2026-10-19 10:25）
- スクリーンショット: `opus/.artifacts/screenshots/`（`npm run screenshots` で再生成。git には入れていない）
- 作業ブランチ: `feature/buzzer-quiz`（main への直接編集が手元の安全フックで止められたため、同じディレクトリでブランチを切った）

テスト名の略記: 単体 = `tests/unit/game.test.ts`、結合 = `tests/integration/room.test.ts`、E2E = `tests/e2e/game.spec.ts`。画像は `.artifacts/screenshots/` からの相対名。

## 画面の見どころ

```
ホーム ──▶ ロビー（5文字のコード・4色の席・👑ホストだけ開始） ──▶ 3,2,1
   ──▶ 出題中（20秒バー・大きな赤い早押しボタン・スペースキー可）
   ──▶ 回答中（本人: 黄色く光る4択と10秒リング／他の人: 「〇〇さんが回答中」）
   ──▶ 正解発表（正解が緑・外れた選択肢に外した人の名前・+10/−5 が得点表に浮かぶ）
   ──▶ 最終結果（メダル・同点は同順位・紙吹雪・ホストは再戦）
```

## 仕様の解釈（課題文に無い点）

詳しくは `ARCHITECTURE.md` の「仕様の解釈」。要点: 19秒目に押した人にも10秒の回答時間を与え、20秒以降の新しい早押しは受け付けない。回答権を得て10秒以内に選ばなければ不正解と同じ（-5点）。切断中の人も席と点数は残る。正解発表は5秒、開始前カウントダウンは3秒。

## 確かめ方の限界

- 「4人」は1台の PC 上の4つの独立したブラウザ（Playwright のコンテキスト。保存領域も別）で確かめた。別々の端末・別々の回線では試していない。
- 「回線断」は Playwright で WebSocket を中継し、接続を切った上で再接続を一定時間拒否して再現した。OS レベルで回線を抜く試験はしていない。
- 効果音（WebAudio の短い音）は鳴らして聞く確認をしていない（作業環境で音を出さない決まりのため）。音が出なくても遊べる作りにしてある。
- デプロイはしていない（課題の決まりどおり）。
