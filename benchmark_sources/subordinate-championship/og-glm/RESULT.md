# RESULT.md

実装: Cloudflare Workers + Durable Objects (WebSocket) + バニラ JS フロントエンド。
「遊び方」11項目・テスト・UI について、項目ごとの確認方法と結果。

- **結合テスト** = `npm run test` (vitest + @cloudflare/vitest-pool-workers、workerd 内で実 WebSocket 接続。`test/room.spec.ts`、12テスト全緑)
- **E2E** = `npm run test:e2e` (Playwright。4つのブラウザページで10問を最後までプレイ。`e2e/quiz.spec.ts`、3テスト全緑)
- スクリーンショットは `.artifacts/screens/{pc,sp}/` (git 非コミット)

### 解釈を明示する事項 (仕様の範囲で決めたルール)

- **正解が出た時点でその問題を締めて reveal → 次の問題へ** (同一問題で複数人の正解加点を認めない、一般的な早押しクイズの挙動)。誰も正解できない場合は誤答ロック全員 or 20秒で終了。→ `ARCHITECTURE.md` 記載
- 回答10秒のタイムアウトは失点なしで回答権はく奪 (その問題では以後押せない)。
- ゲーム進行中の新規参加は不可 (再接続は可)。ロビー中のホスト退出時は接続中の先頭プレイヤーにホストを譲渡。
