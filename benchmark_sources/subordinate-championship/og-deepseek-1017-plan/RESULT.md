# RESULT

「遊び方」11項目・テスト・UIについて、確かめた方法と達成度をまとめます。
判定は **達成 / 一部 / 未達** の3つです。

- 単体テスト: `tests/unit/game.test.ts`（vitest、22件）
- ブラウザテスト: `tests/e2e/quiz.spec.ts` / `tests/e2e/screenshots.spec.ts`（Playwright、11件）
- スクリーンショット: `.artifacts/`（git 管理外）

すべて `npm test` で実行できます（型検査 → 単体 → ブラウザ）。

## 遊び方の11項目

| # | 内容 | 確かめた方法 | 判定 |
|---|---|---|---|
| 1 | 名前を入れて「部屋を作る」／部屋コードで「参加する」 | E2E「1. 定員は4人で、5人目には理由が出る」（作成と参加）。画面は `.artifacts/lobby-pc.png` / `.artifacts/lobby-mobile.png` | 達成 |
| 2 | 定員4人。5人目は入れず理由が画面に出る | E2E「1. …5人目には理由が出る」で、5人目の画面に「満員です（4人まで）」が出て、ロビーに入れず4人のままであることを確認。単体「定員は4人で、5人目は入れない」 | 達成 |
| 3 | ホストが「開始」。開始できるのは2〜4人 | 単体「2人未満では開始できない」「2〜4人で開始できる（3人の場合）」「開始できるのは部屋を作った人（ホスト）だけ」「開始後の新規参加は拒否する」。E2E は2人と4人で実際に開始（テスト2,4,5,7,8,9） | 達成 |
| 4 | 4択の日本語問題を内蔵から10問出す | 単体「内蔵の問題は12問以上あり、10問を重複なく出す」（16問を内蔵）。外部APIは不使用（`src/questions.ts` のみ）。E2E「8. 10問遊び切ると…」で10問出題 | 達成 |
| 5 | 全員に早押しボタン。サーバーが最初に受け取った1人だけが回答権 | 単体「4人の押す順が24通りでも、回答権は最初の1人だけが得る」（全24通り）。E2E「2. 4人が同時に押しても回答権はちょうど1人（3問くり返す）」で、4択が有効な画面がちょうど1つになることを確認 | 達成 |
| 6 | 回答権の人は10秒以内に4択。正解 +10、不正解 -5 | 単体「正解は +10 点で reveal に進む」「不正解は -5 点…」「回答は10秒たつと -5 点で失格」。E2E「6b. …実時間の10秒で -5 点」「4. 再読み込み…」で +10、「3. 不正解…」で -5 を確認 | 達成 |
| 7 | 不正解の人はもう押せない。残りの人で早押しを再開 | 単体「失格した人はもう押せない」「不正解は -5 点で…残りがいれば早押し再開」。E2E「3. 不正解…」でボタンが無効になり「この問題はもう押せません」が出ることを確認。「6b. …」で残りの人のボタンが有効に戻ることを確認 | 達成 |
| 8 | 全員押せなくなるか20秒で正解を全員に表示し、次の問題へ | 単体「全員失格になったら reveal する」「問題が出てから20秒で… reveal」「reveal が3秒続いたあと次の問題に進む」。E2E「6a. …実時間の20秒で正解が表示される」（20秒→正解ハイライト→第2問）、「3b. 全員が不正解になると正解が表示され、次の問題へ進む」 | 達成 |
| 9 | 10問終わったら最終順位を全員に表示 | E2E「8. 10問遊び切ると4つの画面に同じ最終順位が出る」。単体「同点は同じ順位にする」。画面は `.artifacts/result-pc.png` / `.artifacts/result-mobile.png` | 達成 |
| 10 | 再読み込み・一時的な回線断でも同じプレイヤーとして点数を保って復帰 | E2E「4. 再読み込みしても同じ名前・点数で復帰する」（+10点のまま復帰）。E2E「5. 回線を5秒切って戻すと自動で再接続し、ほかの画面の表示が消える」 | 達成 |
| 11 | 点数・残り時間・誰が回答中かが全員の画面でそろう | 点数: E2E「3. 不正解…」で4画面すべてに -5。残り時間: E2E「7. 4つの画面の残り時間の差が1秒以内」。回答中: E2E「2. …」と「9. …」で、回答中バナーが全員に出る（`.artifacts/answering-pc.png` / `.artifacts/answering-mobile.png`） | 達成 |

## テストについて

| 種類 | ファイル | 実行 | 主な内容 |
|---|---|---|---|
| 型検査 | `tsconfig.json` | `npm run typecheck` | 本体とテストの型を検査 |
| 単体 | `tests/unit/game.test.ts`（22件） | `npm run test:unit` | 純粋関数 `game.ts` の規則。定員・開始条件・24通りの同時押し・点数・時間切れ・reveal・10問終了・同順位・状態に正解を含めないこと |
| ブラウザ | `tests/e2e/quiz.spec.ts`（10件） | `npm run test:e2e` | 4つの独立ブラウザで参加・同時押し・不正解・全員不正解・再読み込み・5秒の回線断・実時間20秒・実時間10秒・残り時間の同期・10問完走 |
| ブラウザ | `tests/e2e/screenshots.spec.ts`（1件） | `npm run test:e2e` | PC幅とスマホ幅での撮影、スマホでの操作要素の可視確認 |

特に指示のあった3点:

- **同時押しで1人だけが回答権**: 単体で24通りすべて、E2Eで4人が同時に押して4択が有効な画面がちょうど1つ（3問くり返し）。
- **再読み込みで復帰**: E2Eで、点数が入った状態から再読み込みし、同じ名前・同じ点数・「あなた」表示で復帰することを確認。
- **4人が同時に遊べる**: E2Eの多くが4つの独立ブラウザで進行。テスト1はPC幅3つ＋スマホ幅1つの4ブラウザで部屋を作り、テスト8・9では4人／2人で10問を完走。

E2Eは実時間で動かしており、20秒・10秒・3秒の待ち時間を縮めていません。

## UIについて

- 明るいクイズ番組風。白に近いカード、濃い紺の文字、大きな赤い早押しボタン。色は CSS 変数（`public/style.css` の `:root`）。
- 画面は4つ: 入口・ロビー・ゲーム・結果。
- ゲーム画面: 上に「第N問 / 10」と残り時間の棒、中央に問題文と4択（2×2）、下に早押しボタン、横（スマホでは下）に参加者の点数一覧。
- 回答中の人はカードを強調し、全員に「○○さんが回答中…」を表示。失格者のボタンは無効化して理由を出す。
- スマホ幅（390×844）では、問題文・4択・早押しボタンがスクロールせずに1画面に収まる。E2E「9. …」で `toBeInViewport()` により問題文と早押しボタンが画面内にあることを確認。点数一覧はその下。
- 残り時間は `serverNow` との差で計算するので、端末の時計がずれても全員そろう。
- スペースキーでも早押しできる。

## 達成度の補足・残る制限

- E2Eのブラウザは Chromium のみ。Firefox / WebKit では未確認（**未達**ではなく未実施。対象外と判断）。
- 「4人が同時に遊べる」はヘッドレス Chromium の4コンテキストで確認しており、別々の実機・別回線での確認はしていない。
- 実際の Cloudflare へのデプロイは行っていない（課題の決定事項どおりローカル実行のみ）。
- wrangler 起動時に `Request.cf` の警告（ネットワーク制限による）が出るが、ローカル動作には影響しない。
