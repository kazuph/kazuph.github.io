# 課題: 4人オンライン対戦の早押しクイズ（Cloudflare・ローカル開発限定）

あなたは上司（親エージェント）から、この課題を1人で任された部下です。
同じ課題を、別のエージェントもそれぞれ別のディレクトリで受けています。成果物は上司が採点します。

## 作るもの

Cloudflare 上で動かす前提の、4人がオンラインで同じ部屋に入って対戦する早押しクイズのWebアプリ。
**動かすのはローカル開発環境（`wrangler dev` など Cloudflare 公式のローカル実行）だけ**です。

### 遊び方（必須の機能）

1. プレイヤーは名前を入れて「部屋を作る」か、部屋コードを入れて「参加する」。
2. 1部屋の定員は4人。5人目は入れず、理由が画面に出る。
3. 部屋を作った人（ホスト）が「開始」を押すとゲームが始まる。開始できるのは2〜4人のとき。
4. 問題は4択で、アプリに内蔵した日本語の問題を10問出す（外部APIから取らない）。
5. 問題が出たら、全員の画面に早押しボタンが出る。**サーバーが最初に受け取った1人だけ**が回答権を得る。
6. 回答権を得た人は10秒以内に4択から選ぶ。正解は+10点、不正解は-5点。
7. 不正解の人はその問題ではもう押せない。残りの人で早押しを再開する。
8. 全員が押せなくなるか、問題が出てから20秒たったら、正解を全員に表示して次の問題へ進む。
9. 10問終わったら最終順位を全員に表示する。
10. ゲーム中にブラウザを再読み込みしたり回線が一時的に切れたりしても、同じプレイヤーとして点数を保ったまま復帰できる。
11. 点数・残り時間・誰が回答中か、が全員の画面でそろって見える。

### 決定済み事項（変えてはいけない）

- 実行環境は Cloudflare Workers のランタイム。ローカルでは `wrangler dev`（または Cloudflare 公式の Vite プラグイン）で動かす。
- **デプロイしない**。Cloudflare アカウントへのログインも不要な構成にする。
- アプリの URL は `http://localhost:8787`。ほかのエージェントとポートがぶつからないよう、このポート以外で開発サーバーを常駐させない（テスト内で一時的に別ポートを使うのは可）。inspector など補助ポートも `8787` に関係ない固定値を避け、ぶつかったら自分で変える。
- 有料の外部サービス・外部のリアルタイム配信サービスは使わない。Cloudflare の機能の中で完結させる。
- 正誤判定・点数・早押しの順番はサーバー側で決める（ブラウザの申告を信用しない）。

### 自分で選ぶこと（採点対象）

- **アーキテクチャ**: Cloudflare のどの機能をどう組み合わせるか（例: Workers・Durable Objects・WebSocket・D1・KV など。これらは例であり、選び方は自由）。選んだ理由と、選ばなかった案を `ARCHITECTURE.md` に書く。
- **テスト**: どこを何で確かめるか（単体・結合・ブラウザE2E）。特に「同時押しで1人だけが回答権を得る」「再読み込みで復帰できる」「4人が同時に遊べる」を確かめるテストを含める。テストの実行コマンドを `README.md` に書く。
- **UI**: 画面の見た目と操作感。PC幅とスマホ幅の両方で遊べること。見た目の良さも採点に入る。
