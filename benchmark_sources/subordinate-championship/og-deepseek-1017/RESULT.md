## UI

- PC幅（1280×800）と スマホ幅（390×844, deviceScaleFactor 2）の両方でプレイ可能なレスポンシブCSS。
- 早押しは大きな円形ボタン（`Space` キーでも可）、残り時間はリング状カウントダウン、残り3秒で赤く点滅。
- 回答中は該当プレイヤーのスコアカードをハイライトし、フェーズバッジに「◯◯さんが回答中…」を表示。
- 正解発表では正解を緑、自分の誤答を赤でハイライト。
- スクリーンショット（`.artifacts/`, git管理外）:
  - ロビー: `lobby-pc.png` / `lobby-mobile.png`
  - 出題中: `question-pc.png` / `question-mobile.png`
  - 回答中: `answering-pc.png` / `answering-mobile.png`
  - 結果: `result-pc.png` / `result-mobile.png`
  - 取得コマンド: `npm run screenshots`

## 未達・限界・代用

- 「回線が一時的に切れる」は、実際のネットワーク断ではなく **WebSocket のクローズ→同じ playerId で再接続**（結合テスト）と **ページリロード**（E2E）で確認しています（代用）。
- 「もう一度あそぶ」（ホストの再戦）はエンジンの単体テスト`resetToLobby で点数が0に戻りロビーへ帰る`のみで、UIからの通し操作は未確認です（未検証）。ボタンの表示条件（ホストのみ）は実装済み。
- ホストがゲーム中に切断した場合、他プレイヤーへのホスト自動委譲は行いません（同じIDで復帰すればホストのまま。ロビー中の切断は枠を空けて委譲します）。終盤でホストが復帰しない場合「もう一度あそぶ」は押せません。
- 定員4・開始2人以上などはすべて実時間の締切で動作します。単体テストでは `now` 注入による仮想時間、結合/E2Eでは実時間（正解表示4秒）で確認しています。
