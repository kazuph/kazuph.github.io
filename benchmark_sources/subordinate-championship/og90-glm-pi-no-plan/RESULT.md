# 検証結果（RESULT）

「遊び方」11項目・テスト・UIについて、項目ごとの「確かめた方法」と「達成/未達」をまとめる。

- **結合テスト**: `npm test`（test/integration/room.test.ts、12件、Workers ランタイム内）
- **E2E**: `npm run test:e2e`（test/e2e/game.spec.ts、3件、実ブラウザ × wrangler dev）
- **スクリーンショット**: `.artifacts/` 配下（`npm run shots` で生成）
- すべて「達成」。代用や未達は明記する。

## 遊び方の11項目

| # | 要件 | 確かめた方法 | 判定 |
| --- | --- | --- | --- |
| 1 | 名前を入れて「部屋を作る」or 部屋コードで「参加する」 | 結合: `部屋の作成・参加`（作成API・参加API・存在しないコードの拒否）; E2E: 3テストとも最初にUIで作成/参加を通す（`test: "4人が同時に遊んで...", "5人目は参加できず...", "ゲーム中に再読み込みしても..."`）。スクショ: `.artifacts/01-lobby-pc.png`, `.artifacts/02-lobby-mobile.png` | 達成 |
| 2 | 定員4人。5人目は入れず、理由が画面に出る | 結合: `5人目は参加できず、理由が返る`（API が 409+「満員です（1部屋4人まで）」）; E2E: `5人目は参加できず、理由が画面に出る`（ブラウザ上で #top-error に「満員」と表示） | 達成 |
| 3 | ホストが「開始」。2〜4人のときだけ開始できる | 結合: `1人しかいないときはホストでも開始できない`（サーバーがエラーを返す）、`2人ならホストが開始できる`（ホスト以外の開始要求も拒否）; E2E: `4人が同時に遊んで...`（4人で開始→10問完走）、`ゲーム中に再読み込みしても...`（2人で開始）。UI ではロビー人数が1人のときボタンは disabled | 達成 |
| 4 | 内蔵した日本語4択10問（外部API不使用） | コード: `src/shared/questions.ts`（10問・4択・日本語、外部API呼び出しなし）。結合: `4人で開始から最終順位まで...` で questionIndex が 0→9 まで進み、10問ちょうど出題されることを確認（`expect(final.room.questionCount).toBe(10)`） | 達成 |
| 5 | 問題が出たら全員に早押しボタン。**サーバーが最初に受け取った1人だけ**が回答権 | 結合: `2人が同時に押しても回答権は1人だけ`（連続送信→観察「回答中プレイヤー数=1」）、`4人が同時に押しても回答権は1人だけ`、後から押した3人目が回答権を奪えないことも確認。実装は DO（直列実行）での到着順採番 | 達成 |
| 6 | 回答権者は10秒以内に4択を選択。正解+10 / 不正解-5 | 結合: `正解は+10点で正解表示になり、不正解は-5点でもう押せず早押しを再開する`（得点・delta・lockedOut を検証）、`回答制限時間（10秒）を過ぎると失答で-5点...` | 達成 |
| 7 | 不正解者はその問題ではもう押せない。残りの人で早押し再開 | 結合: 上記不正解テスト内で `lockedOut=true` → `subPhase` が `buzzing` に戻り他のプレイヤーが回答権を取得できることを検証。E2E: フルゲームテストで不正解→復帰→再挑戦の流れが実際の画面で動作 | 達成 |
| 8 | 全員が押せなくなる か 問題出題から20秒 で正解を全員に表示して次へ | 結合: `全員が押せなくなったら（連続不正解で）正解表示へ進む`、`誰も押さないと制限時間（20秒）後に正解表示へ進む`（タイマーの締切はアラームで処理）。※タイマー系はロジック同一・待ち時間だけ短くした `fast` モードで検証（代用: 通常モードは 10秒/20秒/4秒 定数を同じくそのまま） | 達成 |
| 9 | 10問終わったら最終順位を全員に表示 | 結合: `4人で開始から最終順位まで一通り遊べる`（phase=results、プレイヤー数4、スコア整合）; E2E: `4人が同時に遊んで最終順位まで完走できる`（4人全員のブラウザで結果画面+スコア降順を検証）。スクショ: `.artifacts/08-result-pc.png`, `.artifacts/09-result-mobile.png` | 達成 |
| 10 | 再読み込み・一時切断でも同じプレイヤーとして点数を保って復帰 | 結合: `一度切っても同じプレイヤーとして点数を保ったまま復帰できる`（切断→再接続→同一 playerId・同一点数→そのまま回答も可能）; E2E: `ゲーム中に再読み込みしても同じプレイヤーとして復帰できる`（回答→加点→reload→同得点で復帰→ゲーム続行）。実装は DO Storage に状態永続化+トークン再接続 | 達成 |
| 11 | 点数・残り時間・誰が回答中かが全員の画面でそろう | サーバーは状態が変わるたび全員に同一スナップショットを配信（結合テスト全般で各クライアントの受信状態を検証）。E2E: `4人が同時に遊んで...` で4画面が同時に進行・完走。スクショ: `.artifacts/03-question-pc.png`, `.artifacts/05-answering-pc.png`（得点バー/残り時間バー/「回答中」バッジ/回答者名が同時に見える） | 達成 |
