# 早押しバズール — 4人オンライン対戦 早押しクイズ

Cloudflare Workers + Durable Objects で作る、4人が同じ部屋で対戦する早押しクイズです。
**ローカル開発専用**（`wrangler dev`）。Cloudflare アカウントへのログイン・デプロイは不要です。

## 起動方法

```bash
npm install        # 依存関係（node_modules が既にあるなら不要）
npm run dev        # wrangler dev が http://localhost:8787 で起動
```

ブラウザを 4 つ（または通常ブラウザ + プライベートウィンドウ等）開き、
`http://localhost:8787` にアクセスします。

1. 1人目が名前（1〜12文字）を入力して「部屋を作る」→ 4文字の部屋コードが表示される
2. 残り3人は名前と部屋コードを入れて「参加する」（5人目は「満員です」と表示されて入れません）
3. ホストの「クイズ開始」ボタン（2人以上で押せる）でゲーム開始
4. 出題されたら早押し。サーバーが最初に受け取った1人だけが回答権を得て、10秒以内に4択から選択
   - 正解 +10点 / 不正解 -5点（10秒以内に選ばないと失答 -5点）
   - 不正解の人はその問題ではもう押せません。残りの人で早押しを再開します
5. 「全員が押せなくなる」か「問題が出てから20秒」で正解を全員に表示し、次の問題へ
6. 10問終わったら最終順位を全員に表示。ホストは「もう一度遊ぶ」でロビーに戻れます

### ポートについて

- アプリ本体: `http://localhost:8787`（決定済み事項のとおり固定）
- wrangler の inspector は `17929`（他エージェントとぶつからないよう固定変更済み）

### ゲーム中の再読み込み・一時切断

同じブラウザなら localStorage に参加情報（部屋コード + プレイヤートークン）を保存しているため、
再読み込みや一時切断の後も**同じプレイヤーとして**自動再接続し、点数を保ったまま復帰できます。

## テスト

| レイヤ | 内容 | コマンド |
| --- | --- | --- |
| 結合テスト（Workers ランタイム内） | DO のゲームロジック（同時押し・採点・タイマー・再接続・満員・開始制限・4人同時フルゲーム） | `npm test` |
| ブラウザE2E | 実ブラウザ × wrangler dev。4人同時フルゲーム、5人目の拒否、再読み込み復帰 | `npm run test:e2e` |
| 型チェック | Workers 用 / E2E 用の2プロジェクト | `npm run typecheck` |

```bash
npm test           # 結合テスト 12件（約30秒）
npm run test:e2e   # E2E 3件（約2分。8787ポートが空いている必要あり）
npm run typecheck
npm run shots      # スクリーンショット生成 → .artifacts/（先に npm run dev が必要）
```

- 同時押し・タイマー系テストは、ゲームロジックを一切変えずに待ち時間だけ短くした
  `fast` モード（部屋作成時オプション、テスト専用）で検証しています（通常モードは 10秒/20秒/4秒のまま）。
- Playwright の webServer 機能が `wrangler dev` を自動起動・終了するので、E2E 実行中は应用本体を事前に
  手動起動しておく必要はありません。

## ディレクトリ構成

```
src/
  worker/index.ts     # Worker: 部屋作成・参加API、WS中継、静的アセット配信
  worker/room.ts      # RoomDO: 部屋ごとのゲーム状態・ロジック（正誤判定・点数・早押し・タイマー）
  shared/types.ts     # サーバー⇄クライアントのメッセージ型・定数
  shared/questions.ts # 内蔵クイズ10問（4択・日本語・外部API不使用）
public/               # クライアントSPA（Vanilla JS・ビルド不要）
test/integration/     # 結合テスト（Workers ランタイム内）
test/e2e/             # ブラウザE2Eテスト（Playwright）
scripts/screenshots.mjs # 採点用スクリーンショット生成
```

詳細な設計判断は `ARCHITECTURE.md`、検証結果は `RESULT.md` を参照してください。
