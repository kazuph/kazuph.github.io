# 読んだら負け。

「X（旧Twitter）で一番バズるゲームを作ってください」への提案。30秒で文字の色を答える、ルール反転型のブラウザゲームです。流行の実績やバズの保証ではなく、以下の拡散仮説に基づいて制作しました。

## なぜXでバズると考えたか

- **スクリーンショットだけで挑戦したくなる。** 緑色で書かれた「アオ」と「この文字の色は？」だけで、ルールと罠が伝わる。「こんなの簡単」という第一印象が、実際の失敗との落差になる。
- **失敗が自分の話になる。** 必要なのは知識でも長い練習でもなく、「読まずに見る」こと。わかっていたのに間違える体験を「指が勝手に押した」「急に読めなくなった」と言語化しやすい。
- **途中の反転に見せ場がある。** 5問正解するごとに、色を答えるルールと書かれた文字を読むルールが反転。上手くなった直後の油断を突くので、単純な色当てだけでは終わらない。
- **30秒で再戦と比較ができる。** 結果は正解数、反転回数、回答履歴の緑・赤。X投稿には「私の○問、超えられる？」を添える。同じ日付では同じ問題列なので、友人同士で再挑戦しやすい。
- **広告も登録も音もない。** リンクから直ちに練習でき、スマホのタップでもPCの数字キーでも遊べる。通勤中や仕事の合間にも音を出さずに遊べる。

## 遊び方

1. 最初の練習で、緑色の「アオ」に対して「ミドリ」を押してみる。
2. 「30秒、挑戦する」で3秒カウントダウン後に開始。
3. 黄緑の指示は **文字のインクの色** を答える。紫の指示は **書かれている文字の意味** を答える。常に上の指示が優先。
4. 回答は4択。タップ／クリック、または左から数字キー **1・2・3・4**。モバイルでは上段左・上段右・下段左・下段右。
5. 正解で1点。5正解ごとにルール反転。誤答は残り時間が3秒減り、正しい選択肢と説明を表示する。
6. 制限時間終了で結果表示。「もう一度」で同じ日の問題に再挑戦。「Xで結果をシェア」は投稿作成画面を開き、実際の投稿は本人が行う。「結果をコピー」も使用できる。

色の識別を使うゲームです。結果は医療的・科学的な能力診断や人口内順位ではありません。結果の称号はゲーム上の演出です。

## 起動

**`index.html` をブラウザで開くだけ。** ビルド、通信、ライブラリ、アカウントは不要。外部アクセスが発生するのはXシェアを本人が押したときだけです。

ローカルサーバーを使う場合：このディレクトリで `python3 -m http.server 18765 --bind 127.0.0.1` を実行し、`http://127.0.0.1:18765` を開きます。

公開時は `index.html`・`style.css`・`game.js` を同じディレクトリの静的ホスティングへ配置します。公開URLではシェア文に日付付きURLが自動追加され、日付が変わっても同じ問題列を共有できます。file URLやlocalhostは他人から到達できないため投稿文に含めません。公開デプロイは本ベンチマークの範囲外です。

## 設計値と公平性

本課題の「何を作るかから考える」に基づくゲーム仕様。主要な値は `game.js` の `RULES` にまとめています。

| 設定 | 値 | 意図 |
|---|---:|---|
| 本番時間 | 30秒 | 短い挑戦と再戦の単位 |
| 開始カウント | 3秒 | 画面切替後に操作位置を確認する時間 |
| 反転間隔 | 5正解 | 慣れたタイミングで注意の切替を要求 |
| 誤答ペナルティ | 3秒 | 連打より正確さを重視 |
| 正解後の入力停止 | 150ms | ダブルタップによる次問への誤入力を防止 |
| 誤答後の説明 | 650ms | 正解を確認する時間。時計は止まらない |

文字の色と意味は常に異なります。問題列は日付を種にした乱数で固定。出題は正誤に関係なく1問ずつ進み、ルールは累積正解数で反転します。したがって同じ問題列でも、プレイ状況により指示が異なります。通信ランキングや不正防止を謳うものではありません。

時間は単調増加時計で計算し、タブを離れても停止しません。自己ベストだけを端末のlocalStorageに保存します。保存できない環境では結果にその旨を表示し、その回のプレイは続けられます。リセットしたい場合はブラウザのサイトデータから削除してください。

## 実装・検証の境界

単一の静的Webアプリ。既存アセット、手描きアイコン、画像生成、外部フォント、音声、API、他AIは使用していません。画面の大きな色文字はゲームの出題そのものであり、画像素材ではありません。

ブラウザの実操作テストと画面寸法の検証結果は `VERIFICATION.md` に記録します。バズるかどうかと最終的な面白さの評価は、人間のプレイレビューおよび公開後の実績が必要です。
