# ぺらぺらの はしと おやつの むこうがわ

**まずは [絵本をひらく（index.html）](index.html)。** ブラウザで上から下へ読む、全16ページのSTEM絵本です。

- **[PDFで読む・印刷する（book.pdf）](book.pdf)** — 210 × 210 mm、全16ページ。正方形の絵本です。A4に印刷する場合は「用紙に合わせる」を選んでください。
- [本文を読む（manuscript.md）](manuscript.md) — 文章を参照するための原稿。

対象は5〜8歳。読み聞かせ約10分が目安です。実験は読み終わってから、好きなときにどうぞ。

## どんなお話？

雨の日、きつねのコンとうさぎのミミは、机の上に「おやつのしま」をつくります。ところが紙の橋は、へにゃん。紙を増やす代わりに形を変え、同じ条件で比べてみることにしました。

物語12ページに、表紙、親子でできる実験2ページ、解説・奥付1ページを加えた1冊です。観察・予想・試作・比較・改善を通して、形と曲がりにくさの関係に触れます。個数を数え、差を求める場面もあります。

## 読み方

`index.html` をダブルクリックするか、ブラウザにドラッグしてください。インストールやサーバーは不要です。絵も同梱しており、外部サイトへの接続なしで読めます。HTML版を移動するときは `assets/` を一緒に移動してください。PDFは単体で渡せます。

macOSで開く場合：

```sh
open -a 'Google Chrome' benchmark_sources/opus55-vs-astra/astra/stem-book/index.html
```

## 実験について

物語の「1こ・3こ」は架空の結果です。実際の紙でその数を支えられると保証するものではありません。実験では同じ紙・支点間隔・重り・置き方をそろえ、折り方を比較します。大きくたわむか重りが落ちたら止め、その直前までの個数を記録します。重りが足りなければ「ここまで確認」と書きます。

軽い物を使い、大人と机の上で行ってください。人やペットは乗せません。小さな物の誤飲や紙の端にも気をつけてください。実物を使った耐荷重試験は、本の制作時には実施していません。
