# 姫路城ジオラマ — 制作ノート

`index.html` をブラウザで開くだけで動きます（Three.js r160 を jsDelivr から読み込み）。形状・テクスチャはすべてコードで生成しており、外部の3Dモデルや画像ファイルは使っていません（瓦・石垣・漆喰・土塀・木目・土層・銘板はすべて Canvas で描いています）。

操作: 左ドラッグで回転、ホイールでズーム、右ドラッグで移動。右上のボタンで「朝／昼／夕／夜（ライトアップ）」、「桜⇔新緑」、名称ラベルの表示、自動回転、正面視点への復帰を切り替えられます。

## 再現にあたって意識した姫路城の特徴

### 天守群
- **連立式天守**: 大天守・西小天守・乾小天守・東小天守の4棟を、イ・ロ・ハ・ニの渡櫓で「口」の字につなぎ、中庭を囲む配置にしています。大天守は南東の角に置きました。
- **大天守（外観五重）**: 5段の壁を上に行くほど小さく積み、最上層は入母屋屋根としました。棟は東西方向に通し、両端には**銀灰色の鯱**を載せています（姫路城の鯱は金ではなく瓦製のため）。
- **破風の重なり**: 姫路城らしさの中心と考え、各重に次の破風を振り分けました。
  - 二重目の東西面に大きな**入母屋破風**
  - 南北面に対になった**比翼千鳥破風**
  - 三重目と四重目に**千鳥破風**と**唐破風**を交互に配置
  - 唐破風は、中央が膨らんで両端が反り上がる曲線を式で作っています。破風の頂部には**懸魚**の飾り金具を付けました。
- **白漆喰総塗籠**: 壁に加え、軒先・軒裏・破風板まで白で塗り分けています。**瓦の継ぎ目の白い目地漆喰**もテクスチャで表現し、「白鷺城」らしい白さが屋根まで続くようにしました。
- **屋根の反り**: 軒の断面は、下ほど緩く上ほど急になる曲線にしています。隅の軒先は跳ね上げ（軒反り）、隅棟と鬼瓦も付けました。
- **石落とし**（大天守一重目の四隅の張り出し）と、格子窓の並びを入れています。

### 縄張り（城全体の配置）
- **平山城の段構成**: 姫山の上に、低いほうから三の丸 → 二の丸 → 本丸（備前丸）→ 天守曲輪 → 大天守台と、石垣の段を積み上げています。
- **扇の勾配**: 石垣は、裾が緩く上ほど垂直に反り上がる曲面で作りました。石積みの模様は乱積み風に描いています。
- **菱の門**: 登城坂を上った先の櫓門です。菱形の飾り金具と唐破風を付けました。
- **西の丸**: 西側に**百間廊下**をL字に配し、北東の端に**化粧櫓**、角にワの櫓・カの櫓を置きました。曲輪の中は桜の名所として桜を植えています。
- **三国堀**: 二の丸の池として、石の縁取り付きで配置しました。
- **内堀・桜門橋・大手門（高麗門）**: 内堀の両岸も石垣にしています。**土塀**の各所には **○△□ の狭間**（鉄砲や矢を放つための穴）を描き込みました。

## ジオラマとしての工夫
- **模型らしい台座**: 木目の二段台座と真鍮の銘板を用意しました。銘板には「国宝 姫路城　白鷺城」と刻んでいます。盤面の縁は**土層の断面**として見せ、切り取った地面らしさを出しました。
- **地形**: 姫山は、曲輪からの距離に応じてなだらかに下る起伏としました。堀の近くは平地になるよう調整し、登城坂の部分は地形を削っています。
- **植栽**: 約1,800本をインスタンス描画で配置しました。
  - 山の斜面は黒松と広葉樹の雑木林
  - 堀沿いと三の丸は桜並木と桜の群落
  - 松は雲形に仕立て、葉は少し歪ませた多面体でローポリ模型の質感を出しています。
  - 季節ボタンで桜と新緑を切り替えられます。
- **光と質感**:
  - ACES トーンマッピング、柔らかい影、環境光マップを使っています。
  - 屋根はわずかに金属光沢を持たせ、漆喰はマットにして質感を分けました。
  - 水面はクリアコートで映り込みを出しています。
- **時間帯の切り替え**: 朝・昼・夕は太陽の方角・高さ・色と空のグラデーションを変えます。**夜は白い城壁がライトアップで浮かび上がり**、窓に灯りがともります。
- **見せ方**: 初期視点は南東の斜め上からです。菱の門から天守群へ段々に上がっていく構図にしました。名称ラベルは3D座標に追従します。

## 簡略化・既知の差異
- 破風の数と位置、各重の寸法は写真を参考にした概略で、実測値ではありません。
- 大天守台の石垣の高さや曲輪の形は、ジオラマとしての見栄えを優先して単純化しています。
- 内堀は盤面の外周をぐるりと一周させています。実際の姫路城の堀の形とは異なります。
