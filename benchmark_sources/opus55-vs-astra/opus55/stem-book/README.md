## 読み方（エントリポイント）

**`index.html` をブラウザで開いてください。**

```bash
open index.html
# または: python3 -m http.server 8000 → http://127.0.0.1:8000/
```

- 「つぎ ▶」「◀ まえ」ボタン、キーボードの ← →、スマホのスワイプでページをめくれます。

## 科学的な正確さについて

- 影の向き・長さは太陽高度・方位の式（北緯35.7°、太陽時）で計算して描いています。
  - 春分・秋分の正午：高度 約54°、影は身長の約0.72倍
  - 夏至の正午：高度 約78°、影は約0.22倍
  - 冬至の正午：高度 約31°、影は約1.67倍
- 絵の中の方角は「南を向いて見た景色」で統一しています（左＝東、右＝西、手前＝北）。10ページの日時計だけは地図と同じく「上＝北」の俯瞰図です。
- 懐中電灯の影の倍率は「光源〜壁の距離 ÷ 光源〜手の距離」で計算しています。
