# story-serial-craft

Web連載小説を、企画から人物、全体構成、各話プロット、本文、挿絵、読める形への組版、全ページの確認まで通しで作るためのスキルです。12の工程と、渡す前のチェックリスト、行き詰まったときの戻り先の表をまとめています。

- [SKILL.md を読む（GitHub）](https://github.com/kazuph/kazuph.github.io/blob/master/works/yuzuki-yugo/skill/story-serial-craft/SKILL.md)
- [SKILL.md をダウンロード](https://raw.githubusercontent.com/kazuph/kazuph.github.io/master/works/yuzuki-yugo/skill/story-serial-craft/SKILL.md)

使うときは、`story-serial-craft/` フォルダごと、エージェントのスキル置き場（例：`~/.claude/skills/`、`.agents/skills/`）にコピーします。
